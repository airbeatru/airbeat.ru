Arrangement: composing with blocks

Capture, movement, copies, splits, selection and independent block settings.

Add and fill blocks

  1. Open Arrangement, choose composition length and add a drum, bass or chord block. Select a block on its track to open its editor below.
  2. Capture AirBeat copies the active drum pattern and dynamics. Capture AirBass copies the bass phrase and sound. Capture AirChord copies the step progression; Capture AirLooper copies recorded notes, timing and timbres.
  3. Capture replaces the selected block's content. It is independent of the Jam source; Arrangement Undo reverses the capture. Block length is retained and a shorter phrase repeats to fill it.

Build a song structure

Use block properties for name, start and length. Block start is counted from beat 1 in the interface; length uses beats. Drums snap to bars, bass and chords to sixteenths. Numeric fields provide an alternative to dragging.

Use the editor commands to copy, duplicate, paste, split or delete blocks. Set the destination beat for Paste. Select multiple builds a group; Select all blocks and Clear selection manage it. Check the track and selected blocks before group operations.

Zoom and Follow playhead change the view. Small screens scroll the timeline horizontally inside its region. Back to tracks, Previous block and Next block connect the editor with the composition.

Settings for only this block

A chord block can have its own sound, key, level and effects. Following AirChord makes the instrument's changes affect the block; Capture sound or local controls create block-specific settings.

Captured AirLooper notes have fixed pitches: changing the instrument's key does not transpose the copy. The note editor changes pitches, start, length, sound and envelope, and adds or removes events. Phrase starts are counted from beat 0 here.

A bass block stores its own steps, synthesis and Follow Chords. Drum blocks retain pattern and dynamics; AirBeat track sounds and mixer remain shared. AirChord volume and Master also affect the shared output.

Check transitions and keep the result

  1. Choose start bar and Loop boundaries, and enable repetition to rehearse a transition. Pause retains position; Stop resets it.
  2. Check Mute/Solo on the three tracks. They determine which Arrangement parts play and export.
  3. Save the project for later edits. For output, open Export & Record, choose WAV or MIDI and set a range.
