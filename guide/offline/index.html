Installation, offline use and troubleshooting

Prepare a copy, update safely and resolve missing sound, file errors and storage problems.

Prepare the app ahead of timeSave music before updatingIf there is no soundIf work will not open or save

Prepare the app ahead of time

  1. While online, open More → Install & offline and prepare an offline copy. Wait for readiness; it needs the complete app download.
  2. Install through your browser's Install app or Add to Home Screen menu. On iPhone/iPad, open Safari and use Share. Availability depends on the browser.
  3. Download project backups separately. The offline copy contains app files, not your music. Browser cleanup can remove both caches and drafts.

Save music before updating

Check for updates looks for a complete new copy. When ready, review it, finish recording, save the project and confirm reloading. Reload stops audio. Other open tabs do not reload automatically.

Download failures retain the previous copy; try again with a working connection. Remove offline copy removes app files, not IndexedDB projects or downloaded files. It does not create a backup.

If there is no sound

  1. Press Play or a pad: browsers need a user action to start audio. Check device volume, the output device and whether the tab is muted.
  2. Check Master, instrument levels, Mute/Solo, sequencer enable switches and workspace mode. Arrangement plays blocks; Jam plays source patterns. An empty export range provides no notes.
  3. Open sound help and the output meter. If audio could not start, save a project and try an ordinary reload. Do not bypass browser security warnings.

If work will not open or save

When drafts fail, use Save for a downloaded project. Check free space and ordinary browsing mode. Do not clear browser storage before downloading needed projects and the collection.

Check the file type: Open accepts a single project, library import accepts a collection. WAV/MIDI cannot be opened as projects. Damaged and oversized files are rejected while the current session remains intact.

For a failed optional panel, use its retry button when connectivity returns. For an old offline copy, check for updates normally. Save before reloading; another browser does not automatically have your local drafts.
