Suggest a new pattern

  1. In Jam, open the instrument's Pattern variations. Only that pattern changes; sounds and the rest of the music are retained.
  2. Choose Original, Subtle, Balanced or Bolder, then protect important steps. Steps 1, 5, 9 and 13 are protected initially. AirBeat protects an entire six-track column.
  3. Press Create variation. The table compares current steps with the proposal. This is a data preview, not automatic audio preview or application.

Apply only a useful proposal

Stop Jam before applying. Turn off AirBeat's bank chain. Until you apply, the source remains intact.

Apply variation creates one undoable instrument edit. Discard variation abandons the proposal. If source or options changed, generate a fresh proposal.

Tie and Slide links are preserved. Step protection belongs to the current tab and is not saved in project files. If nothing changes, check amount, protection, Mute/Solo and links, then create another proposal.

Explore complete compositions

  1. Open Demo projects in the sidebar, or in More on a phone. Select a composition and preview an excerpt without replacing current work.
  2. To edit its parts, choose to open it and confirm replacement. Download your current project first if needed. Opening a demo does not start playback automatically.
  3. Explore its AirBeat, AirBass and AirChord blocks, change one, compare with Undo and save your version under a different name.

Pattern templates and sound presets differ

AirBeat patterns and AirChord progressions provide starting rhythms and harmony. AirBass sounds and AirChord sound presets change timbre. A user AirChord preset retains a wider set of settings, described in that instrument's chapter.

Use a Jam scene for a three-instrument variation, and a project copy for an independent composition. This keeps experiments separate from versions you want to retain.
