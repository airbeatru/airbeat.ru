A project file is a complete working copy

Save downloads .airbeat.json with instruments, banks, user sounds, scenes, Arrangement and mix settings. Check browser downloads. Pressing Save does not create a cloud copy.

Open validates a file, then asks to replace the current session. Cancel keeps the music. Download current work first if needed. Invalid files and files over 1 MB are rejected without replacement.

New versions read supported older formats. An older app is not guaranteed to read a newer project. Undo history and prepared audio downloads are not part of the project file.

Autosave and recovery

Drafts belong to this browser and device. When a previous session is found, autosave pauses until you choose Restore or Continue separately. This prevents silently replacing earlier work.

Recovery first preserves new edits as a separate draft and replaces the session only after success. Errors retain current music. Continue separately enables autosave under a new identity while retaining the found draft.

Browser cleanup, private mode and storage limits can remove or prevent drafts. If saving fails, use Save immediately for a downloaded file.

Organize My sketches

Search, sorting and favorites help find work. Keep a copy of this session creates an independent entry. Renaming changes its name, not music. Opening another work asks for confirmation.

Previous version, when available, returns to a saved state; it is not an unlimited edit history. Download work you need before deleting it. Project and preset names do not change with interface language.

Transfer the whole library

  1. Under Back up the library, choose Download collection. It includes sketches, favorites and available previous versions. Ensure current music has been saved as a draft or independent copy first.
  2. On another device, open the collection through the library, review the list and confirm adding it.
  3. Independent copies are added. Matching names never overwrite existing work; repeated import adds more copies. Import does not open a project or stop sound. Collections and single projects use different Open commands.
