Sharing a pattern or a sketch

What each link includes, how to accept a sketch and how to transfer a complete project.

Two links with different contents

LinkIncludes / excludes
AirBeat patternActive drum pattern, sounds, mixer, dynamics and tempo. No other banks, instruments or Arrangement.
Jam sketchActive patterns and settings for three instruments, AirChord effects, BPM and Master. No project names, other banks, user libraries, scenes, Arrangement or master mix processing.

Transfer the part you intend

  1. For drums, use Share pattern in AirBeat. For three parts, choose More → Share sketch.
  2. Review the summary, copy the link and send it to your recipient. Musical data are in the link itself; it is not private storage.
  3. The recipient reviews and explicitly applies the proposal. Audio never starts automatically. Save current work before applying; available undo belongs to the current session.

Use a file for complete work

For scenes, a recorded phrase and composition blocks, Save a project file and transfer it. The recipient uses Open. Use a collection for the whole library.

If a link is too large or rejected, use a project file. Link creation does not upload your project to a server or create real-time collaborative editing.
