2. Какие данные обрабатываются

Владелец сайта не использует формы обратной связи, системы веб-аналитики, рекламные пиксели и собственные файлы cookie. Сайт не запрашивает имя, номер телефона, адрес электронной почты и иные персональные данные посетителя.

Синтез звука и запись музыкальных фраз выполняются в браузере. Проекты автоматически сохраняются как локальные черновики в базе IndexedDB на устройстве посетителя. Черновики можно восстановить или удалить в разделе «Черновики»; очистка данных сайта в браузере также удаляет их. По команде «Сохранить» проект скачивается в файл, а по команде «Открыть» выбранный посетителем файл читается локально. Музыка и файлы проектов не отправляются владельцу сайта или хостинг-провайдеру. Доступ к микрофону не запрашивается.

Выбранный вручную язык интерфейса сохраняется только в локальном хранилище вашего браузера. Эта настройка не передаётся владельцу сайта. При первом открытии язык выбирается по настройкам языка и часовому поясу браузера; IP-адрес и внешние сервисы геолокации для этого не используются.

Для технической доставки страниц хостинг-провайдер GitHub Pages может автоматически получать и хранить IP-адрес, дату и время запроса, адрес запрошенной страницы, сведения о браузере и устройстве. Эти данные обрабатываются GitHub как самостоятельным поставщиком сервиса для обеспечения его работы и безопасности. Владелец сайта не получает доступ к индивидуальным IP-адресам посетителей.
