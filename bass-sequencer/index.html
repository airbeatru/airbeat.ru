Online bass sequencer: build a bassline with AirBass

AirBass is a free online bass synthesizer and 16-step sequencer inside AirBeat.ru. Write a bassline, shape its articulation and play it alongside AirBeat drums and AirChord harmony. The sound is synthesized in your browser: no account, installation or uploaded recording is needed.

Make your first bassline

  1. Open AirBass in the studio and confirm the Jam workspace. Your current project is not replaced. Choose a built-in bass sound and start in Manual mode.
  2. Select a step to open its editor. Choose a note and use Preview to hear it. Selecting an existing note keeps it; Make rest is a separate action. If the pattern is empty, place a few notes or use Example pattern.
  3. Enable BassSequencer and press Play. Jam uses the AirBeat tempo. Set note strength with Velocity, note length with Gate, a stronger attack with Accent or a connection to the next note with Slide.
  4. Use Save for an editable project backup. Export & Record can create a Jam loop WAV. To build a longer composition, use To Arrangement and edit independent bass blocks there.

A bass part that fits your music

Manual mode plays the notes you write. Follow Chords follows AirChord harmony while retaining your manual pattern for later use. Choose the following algorithm and octave in the harmony settings; see the detailed AirBass guide for the source of harmony in Jam and Arrangement.

Built-in sounds and synthesis controls let you adjust the bass character. Level and Swing help it sit with the drum groove. Undo and Redo belong to the instrument, so you can compare changes without editing the chord part.

Jam is for looping and live playing. Arrangement places bass, drum and chord blocks on one timeline with a shared tempo. A transferred block is an independent copy, so editing it does not rewrite the source Jam pattern.

Try a simple offbeat bassline

Keep a steady drum loop, write the same low note on a few offbeats and shorten Gate to leave space between notes. Add an octave on the last note and compare Accent on and off. Save a project copy before trying Follow Chords so you can return to your starting point.

Questions and answers

Does AirBass record a real bass guitar?

No. It is a browser synthesizer with a step sequencer, not a microphone or guitar recording tool. Live Record captures the studio master output without using your microphone.

Will Follow Chords erase my written notes?

No. Following harmony and the manual note pattern are separate settings. Returning to Manual restores the written notes. The guide explains which AirChord source is used in each workspace.

Can I export the bassline?

Jam WAV renders the enabled Jam sequencers, so mute parts you do not want in that file. Arrangement WAV renders a composition or range; MIDI exports note and timing data from Arrangement, without embedding the synthesized sounds.
